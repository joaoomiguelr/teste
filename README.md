## Como baixar

- Para baixar um arquivo: abra o link e use o botão de download (seta para baixo / **Download raw file**).
- Para baixar tudo: na página inicial do repositório, clique em **Code → Download ZIP**.

Cada PDF contém capa e uma receita por página: 21 páginas de sobremesas, 21 de petiscos e 16 de bebidas.
